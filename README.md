# 지출 합계

항목별 금액을 입력하면 같은 항목끼리 더하고 전체 합계를 보여 주는 Python 코드입니다. 따로 설치할 패키지는 없습니다.

## 실행

Python 3에서 실행합니다.

```sh
python expense_summary.py food=8000 bus=1500 food=5000
```

```text
bus: 1,500
food: 13,000
Total: 14,500
```

## 입력 방법

- `항목=금액` 형태로 입력합니다.
- 같은 항목을 여러 번 입력하면 합산합니다.
- 항목은 이름순으로 출력합니다.
- 금액은 0 이상의 정수만 받습니다.
- 입력한 내용은 파일로 저장하지 않고 계산 결과만 출력합니다.

문자열 분리, 딕셔너리, 반복문을 사용했습니다.
